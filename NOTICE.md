# Reference and attribution

This project draws on concepts reviewed in
[JordyDutch/multi-provider-orchestration](https://github.com/JordyDutch/multi-provider-orchestration),
including shared project instructions, scoped task briefs, explicit provider/model/effort
selection, capability probes, authorship-aware review, restricted execution contexts,
validated output envelopes, and isolated installer tests.

The TypeScript controller and adapters in this repository are separately implemented.
The upstream scripts are not used to dispatch workers.
